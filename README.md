# zooner_app

Modern, mobile-first local product discovery platform connecting shoppers with nearby physical retailers.

## Overview
**Zooner** helps people discover products available in stores near them, while empowering local brick-and-mortar merchants with high-intent customer footfall and 0% walk-in commission.

## Key Capabilities
- **Customer Discovery Experience**: Real-time shelf inventory explorer, neighborhood filters, category chips, and broadcast product requests.
- **Dedicated Retailer Partner Portal**: Merchant command center demo, footfall analytics, flash offers, flat pricing, and on-page store registration.
- **Embedded Google Maps**: Live interactive map embeds dynamically focused on Coimbatore physical stores with direct turn-by-turn routing.
- **Theme Engine**: Seamless Light & Dark mode support with Electric Indigo & Royal Blue styling.
- **SEO & Geo-targeted**: Structured JSON-LD schema, local meta tags, OpenGraph, and Twitter Cards.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide Icons
